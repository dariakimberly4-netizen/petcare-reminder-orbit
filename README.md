# PetCare Reminder — Orbit Version

**Tagline:** Never Miss Their Care.

Mobile-first pet health, vaccination, grooming, medication, veterinary reminder and clinic-management demo for **Pet Family Animal Clinic and Grooming Center**.

## Included
- Pet Owner Orbit navigation
- Clinic Staff Orbit navigation
- Multi-pet profiles
- Vaccination tracking and due/overdue status
- Smart reminders
- Medication and grooming records
- Vet appointments
- Digital vaccine card with QR
- Document metadata vault
- Emergency pet card
- Clinic customers, pet lookup, reminder center and reports
- localStorage persistence
- Reduced Motion setting
- Large touch targets and mobile-first layout

## Clinic logo
The app expects the supplied clinic logo at:

`assets/pet-family-logo.png`

The uploaded logo should be placed there without redesigning, recoloring or cropping it.

## GitHub Pages
Publish the repository from **main / root** in GitHub Pages settings.

> Demo note: data is stored only in the browser with localStorage. Real accounts, cloud sync, real document storage, SMS/email/WhatsApp delivery, and clinic-grade authentication require a backend integration.

PetCare Reminder helps organize pet records and reminders. For medical advice, diagnosis, vaccination schedules, and treatment decisions, consult a licensed veterinarian.
